**WebMonitor** 是新一代开源网页内容监控平台——用 XPath 精准锁定页面区域，
秒级感知变化，自动邮件触达。React + FastAPI 驱动，Docker 一键部署，
让每一寸你关心的网页都在雷达之上。

## ✨ 核心能力

</div>

- 🎯 **精准监控** — XPath 定位页面任意区域，只关心你指定的那一块
- 📮 **即时触达** — 变化发生即邮件告警，不错过任何一次更新
- 🌐 **动静皆宜** — 静态页面与 React/Vue 动态渲染页面全覆盖
- 💬 **AI 驱动** — 与 Agent 对话即可生成监控脚本，零代码接入
- 🐳 **开箱即用** — Docker 一键自托管，数据完全自有
- 👥 **多用户** — 公开任务 + 用户订阅，适合团队与社区共享
